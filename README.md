# ברכת הנשיא

אתר התדמית של **ברכת הנשיא** — בית תוכנה לפיתוח מערכות ואפליקציות מותאמות
לעסקים בטכנולוגיית AI. אתר סטטי, ללא תלויות ובלי שלב בנייה: כל מה שצריך כדי
לפרוס אותו נמצא בשורש הריפו.

## עלייה לאוויר

האתר מתפרסם מ‑GitHub Pages בכל push ל‑main, ומוגש מהדומיין `birkat-hanasi.co.il`.

**הפעלה חד‑פעמית** (אם Pages עדיין כבוי): Settings → Pages → Source: Deploy from a branch
→ main → / (root) → Save. אין דרך להפעיל את Pages מתוך workflow — ה‑token של Actions מורשה
לפרוס לאתר, לא ליצור אותו.

**הדומיין** מוגדר בקובץ `CNAME` שבשורש. ב‑DNS של הדומיין מוגדרות ארבע רשומות A לכתובות
של GitHub Pages, ולצידן רשומת CNAME מ‑`www` אל `shayh22.github.io`. הכתובת בקובץ `CNAME`
היא הכתובת הקנונית, ו‑GitHub מפנה אליה את הגרסה השנייה מעצמו — כך ש‑`www.birkat-hanasi.co.il`
ו‑`birkat-hanasi.co.il` שניהם עובדים, ותעודת ה‑HTTPS מכסה את שניהם. בהגדרות Pages מסומן
Enforce HTTPS. גם הכתובת הישנה `shayh22.github.io/birkat-hanasi/` ממשיכה לעבוד ומפנה לכאן.

אם הדומיין משתנה: מעדכנים את `CNAME`, את `<link rel="canonical">` ותגי ה‑Open Graph
ב‑`index.html` וב‑`accessibility.html`, את ה‑JSON-LD, ואת הכתובות ב‑`sitemap.xml`
וב‑`robots.txt`.

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `index.html` | עמוד הבית: פתיח, שירותים, פרויקטים, תהליך העבודה ויצירת קשר |
| `accessibility.html` | הצהרת נגישות |
| `styles.css` | כל העיצוב, כולל מצב כהה ותפריט הנגישות |
| `a11y.js` | תפריט הנגישות — גודל טקסט, ניגודיות, גווני אפור, קו תחתון, גופן קריא ועצירת אנימציות |
| `intro.js` | אנימציית הפתיחה של הלוגו |
| `shots/` | צילומי מסך מהמערכות החיות |
| `design/` | קובצי המקור של קנבס העיצוב (Claude Design) |

## נגישות

האתר נבנה לפי תקן ישראלי 5568 (WCAG 2.1 רמה AA): מבנה סמנטי, ניווט מלא
במקלדת, ניגודיות תקנית במצב בהיר ובמצב כהה, טקסט חלופי לתמונות, גדלים יחסיים
בלבד וכיבוד העדפת המערכת להפחתת תנועה. הבחירות בתפריט הנגישות נשמרות בדפדפן
וממשיכות בין העמודים.

לפני עדכון ההצהרה: יש להשלים בה את שם רכז/ת הנגישות.

## החלפת צילומי מסך

מחליפים את הקובץ המתאים ב‑`shots/` (webp, רוחב 480), ומעדכנים ב‑`index.html`
את `width`/`height` ואת הטקסט החלופי כדי שיתארו את מה שרואים בפועל.
