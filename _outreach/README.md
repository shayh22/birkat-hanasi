# ברכת הנשיא – פניות לעסקים

פניות ראשונות במייל לעסקים בשרון (נתניה, כפר יונה, אבן יהודה והסביבה) בשם ברכת הנשיא.

התיקייה נמצאת בריפו של האתר, אבל האתר לא מגיש אותה: GitHub Pages מדלג על תיקיות ששמן מתחיל בקו תחתון. לכן אסור להוסיף לריפו קובץ `.nojekyll`. הריפו ציבורי, כך שהקבצים כאן גלויים לכל מי שנכנס אליו ב-GitHub.

## איך זה עובד

| קובץ | תפקיד |
|---|---|
| `leads.json` | רשימת העסקים: שם, עיר, מייל, עמוד המקור של הכתובת, והבעיה שהמייל מתאר |
| `build.py` | בונה מכל ליד את הנושא ואת גוף המייל, ומפיק את `emails.json`, `emails.csv` ו-`outreach.html` |
| `page_template.html` | התבנית של דף הסקירה |
| `send.py` | שולח מיילים לפי מזהה, דרך Cloudflare Email Sending |
| `sent.jsonl` | יומן השליחה. כל מייל שנשלח נרשם כאן, ו-`send.py` מדלג על מזהה שכבר מופיע בו |

```
python3 build.py                 # אחרי כל שינוי בלידים או בנוסח
python3 send.py vet4us onkor     # שליחה לפי מזהה
```

## כללים (סעיף 30א לחוק התקשורת)

- כל נושא מתחיל ב-`פרסומת |`.
- המייל הראשון מבקש רשות לשלוח הצעה, ונשלח לכל עסק **פעם אחת בלבד**. אין מייל המשך למי שלא ענה.
- בכל מייל מופיעים שם, טלפון, כתובת, ואפשרות להסרה.
- מי שמשיב "הסר" מסומן ולא מקבל עוד מיילים.
